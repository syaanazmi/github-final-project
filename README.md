# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Description

This project provides a simple way to calculate interest without compounding.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal is the initial amount of money.
- Rate is the annual interest rate in percentage.
- Time is the duration in years.

## Usage

Run the `simple-interest.sh` script and enter the principal, rate of interest, and time period when prompted.

## Example

Principal: 1000
Rate: 5%
Time: 2 years

Simple Interest: 100
